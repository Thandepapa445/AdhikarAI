# 📱 Sankalp AI — Citizen Mobile Application
### Jharkhand Societal Innovation & University Collaboration Mobile App
*(React Native & Expo Mobile App for Citizens & Gram Panchayats)*

---

## 🌟 Mobile Features

1. **1-Tap Hardware GPS Geotagging**: Automatically locks device GPS coordinates, District, and Block.
2. **Direct Camera Capture & YOLOv8 Vision**: Takes live photo evidence of hazards (water leakage, potholes, unmanaged waste) and passes them to the AI microservice for verification.
3. **Vernacular Voice Problem Input**: Speak in Hindi or local dialects (Santhali, Mundari, Ho, Nagpuri) to record the issue description.
4. **8-Stage Solution Tracker**: Follows the problem as universities (BIT Mesra, BAU, IIT ISM) build and test solutions.
5. **1-Tap Community Pilot Sign-off**: Panchayat Mukhyas and citizens verify deployed village pilots directly on their mobile phone.

---

## 🚀 How to Run the Mobile App

### 1. Install Expo CLI / Dependencies
```bash
cd "jharkhand-societal-innovation-portal/mobile-app"
npm install
```

### 2. Start Expo Development Server
```bash
npx expo start
```

* **To run on Physical Phone (Android / iOS)**: Scan the generated QR code using the **Expo Go** app from the Google Play Store or Apple App Store.
* **To run on Android Emulator**: Press `a` in the terminal.
* **To run in Web Mode**: Press `w` in the terminal.
